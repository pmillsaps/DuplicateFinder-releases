# Duplicate Finder — releases

Installers for **Duplicate Finder**, a Windows app and CLI that finds duplicate images, videos and exact copies.

**Download:** [DupFind-win-Setup.exe](https://github.com/pmillsaps/DuplicateFinder-releases/releases/latest/download/DupFind-win-Setup.exe) from the [latest release](https://github.com/pmillsaps/DuplicateFinder-releases/releases/latest).

- Installs per user (no admin prompt); Windows 10/11 x64.
- Updates itself: when a new version is published here, the app shows an **Update** button.
- Includes an LGPL build of FFmpeg (https://github.com/BtbN/FFmpeg-Builds).

This repository holds release files only.
